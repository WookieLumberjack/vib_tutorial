# Security policy

vib_tutorial is an educational desktop app. It runs locally, makes no network
connections and stores nothing but its own display settings (the theme and the
virtual test's playback speed). Security problems are unlikely, but reports are
welcome.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately instead: on the
repository's **Security** tab, click **Report a vulnerability**
([direct link](https://github.com/WookieLumberjack/vib_tutorial/security/advisories/new)).
Only the maintainer can see the report.

Please include what you found, how to reproduce it, and which version or commit
you used. This is a hobby project maintained in spare time, so there is no
guaranteed response time, but every report will be read.

## Supported versions

Only the latest commit on `main` is supported; fixes are not backported.

## Not security issues

Wrong or inaccurate results (a frequency, a mode shape, a fitted parameter) are
bugs, not vulnerabilities. As the [README](README.md#disclaimer-and-license)
says, the software is for educational use only and its results are not
guaranteed to be correct.
